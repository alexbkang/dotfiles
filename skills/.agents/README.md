# Skills

These are my curated, modified copies — not pristine upstream files.

Skills are used in a fixed order: `grilling` (settle the design) → `to-spec` (record it to `.scratch/<feature-slug>/spec.md`) → `to-tickets` (split it into vertical-slice tickets under `.scratch/<feature-slug>/issues/`) → `implement` (build from the tickets, working the frontier) → `code-review` (review the diff against the spec and tickets).
