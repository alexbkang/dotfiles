# Skills

These are my curated, modified copies — not pristine upstream files.

## Workflow

Skills are used in a fixed order: `grilling` (settle the design) → `to-spec` (record it to `.scratch/<feature-slug>/spec.md`) → `implement` (build from the spec) → `code-review` (review the diff against the spec). There is no issue tracker; specs are ordinary markdown files under `.scratch/`.
